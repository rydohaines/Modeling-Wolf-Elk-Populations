# Beddington–DeAngelis replacement figures

Run `python Norman/bell/generate_figures.py` from the repository root to recreate these PNGs. They use the shared Beddington–DeAngelis response in `Norman/repo_model_snapshot.py`.

| Replacement | Replaces in the paper |
| --- | --- |
| `simple_model_flow.png` | Figure 1: constant-pressure phase-plane flow |
| `frontier_introduction_schedules.png` | Figure 2: farmer and hunter introduction schedules |
| `frontier_introduction_population_response.png` | Figure 3: population response to introduction shapes |
| `playground2_wolf_vs_elk.png` | Figure 4: gradual pressure versus full force |

When compiling from `VERYIMPORTANTPAPER/`, use paths such as `../Norman/bell/simple_model_flow.png` in `\includegraphics`.
